# 北京公办高中 2025 扩展补录名单（第二批草案）

## 1. 说明

这份文件用于在现有 `106` 所首批 seed 基础上，继续补充 2025 年名单中明确属于北京 8 区、且优先判断为公办普通高中的学校。

它的角色是：

- 作为 `V1` 的扩展补录池
- 优先补足城八区内明显遗漏的公办普通高中
- 先扩充“学校池”，再进入 `school_id / short_name / aliases` 的结构化阶段

## 2. 当前补录原则

- 只补东城、西城、朝阳、海淀、丰台、石景山、通州、大兴
- 优先补“明显属于公办普通高中”的学校
- 对边界不清的学校，保留到后续复核，不直接混入主池
- 民办、国际化学校继续排除

## 6. 当前不直接纳入第二批主池的学校类型

以下类型当前继续排除或暂缓：

- 明显民办学校
- 国际化学校
- 名称边界不清、办学属性待确认学校
- 特殊教育学校

## 7. 下一步建议

第二批补录完成后，建议按这个顺序继续推进：

1. 合并首批 seed 与第二批补录池
2. 为合并后的学校池补 `school_id`
3. 为合并后的学校池补 `short_name`
4. 生成 `aliases` 候选
5. 对高频学校做别名复核
