# 校排入口页面原型说明

## 1. 页面位置

当前小程序页面原型位于：

- `miniprogram/pages/school-rank-entry/index.wxml`
- `miniprogram/pages/school-rank-entry/index.js`
- `miniprogram/app.wxss`

## 2. 当前页面目标

这不是最终生产页，而是一个：

- 可在微信开发者工具中直接打开
- 能展示真实交互结构
- 能体现设计方向
- 能串联“选学校 -> 补输入 -> 看估算结果”主链

的前端原型。

## 3. 当前已实现内容

- 顶部产品主张
- 所在区选择
- 高中搜索输入
- 搜索候选下拉
- 选中学校确认
- 校排名输入
- 年级总人数输入
- 排名口径切换
- 分数补充输入
- 原型级估算结果展示

## 4. 当前仍为原型的部分

当前页面中的以下能力仍然是前端原型逻辑：

- 学校搜索使用的是页面内置示例学校数据
- 估算结果使用的是页面内置演示估算逻辑
- 尚未直接调用 Python 数据层脚本

## 5. 为什么先这样做

因为当前目标是让你先看见：

- 页面层次对不对
- 输入链路顺不顺
- 家长会不会看懂
- 视觉气质是否可信

等页面方向确认后，再把真实搜索接口和真实估算接口接进来。

## 6. 后续接入顺序

建议后续按这个顺序接入真实数据能力：

1. 用真实学校标准库替换页面内置学校数据
2. 用真实搜索接口替换前端本地搜索函数
3. 用真实校排估算接口替换前端演示估算逻辑
4. 最后补推荐结果页
