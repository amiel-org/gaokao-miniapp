# 微信开发者工具首次体验反馈修复记录

日期：2026-04-27

## 1. 用户反馈

首次在微信开发者工具中跑通页面后，发现以下问题：

1. 首页需要增加“一模 / 二模分数”，但不应作为必填。
2. 搜索学校后虽然出现候选，但用户还要手动点选，首次操作会以为已经可以直接估算。
3. 北京定位结果页顶部导航标题出现乱码。
4. 点击“继续看冲稳保”后只弹出提示，不像一个完整产品路径。

## 2. 本次修复

### 2.1 首页增加一模 / 二模分数

校排入口页将原来的“分数（可选）”改成：

- 一模
- 二模
- 不确定

分数仍然不是必填。

### 2.2 学校搜索自动选中强匹配结果

当搜索结果第一项是强匹配时，系统自动选中该学校，并展示“已选中这所学校”的提示。

这样用户输入“汇文中学”这类明确学校名后，不需要再困惑是否还要点一次。

### 2.3 修复结果页导航标题乱码

将结果页 `index.json` 的标题修复为：

`北京定位结果`

### 2.4 增加冲稳保预览页

新增页面：

`miniprogram/pages/volunteer-preview/index`

当前不是最终推荐页，而是预览页。

它根据当前定位区间生成：

- 冲
- 稳
- 保

三个层次的参考位次范围，让用户点击“继续看冲稳保”后能进入下一步页面，而不是只看到 toast 提示。

## 3. 当前边界

冲稳保预览页仍是产品路径占位，不是最终推荐算法。

正式版本还需要接入：

- 院校专业组。
- 近三年录取位次。
- 选科要求。
- 专业限制。
- 体检限制。

## 4. 后续建议

下一步建议：

1. 在微信开发者工具中重新编译。
2. 再次测试“汇文中学”是否能自动选中。
3. 再次进入定位结果页，确认顶部标题不再乱码。
4. 点击“继续看冲稳保”，确认能进入冲稳保预览页。
