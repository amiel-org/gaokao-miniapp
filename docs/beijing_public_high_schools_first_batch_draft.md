# 北京公办高中首批名单草案

## 1. 说明

这是一份用于 V1 开发阶段的“首批名单草案”，不是最终权威名录。

当前用途：

- 作为北京公办高中标准库的第一批 seed 数据
- 作为学校搜索、aliases 补全、校排转市排规则设计的基础候选池
- 作为后续人工复核和官方名单校对的工作底稿

## 2. 当前工作口径

为便于 V1 快速推进，当前将“城八区”暂按以下 8 个区处理：

- 东城区
- 西城区
- 朝阳区
- 海淀区
- 丰台区
- 石景山区
- 通州区
- 大兴区

如果后续你希望调整“城八区”的业务口径，可以整体替换，不影响当前结构设计。

## 3. 选入原则

当前草案遵循以下原则：

- 仅纳入公办高中或公办体系内高中校区/学校
- 优先纳入北京家长高频认知学校
- 优先纳入普通高中志愿场景中高频出现学校
- 暂不纳入明显民办、国际化或特殊教育学校
- 允许后续根据官方最新名单增删

## 4. 当前参考来源

当前首批草案主要参考：

- 北京市人民政府门户网站 2024 年 5 月 23 日发布的《北京市2024年具有招生资格的高级中等学校名单公示》
  链接：

说明：

- 该来源可公开访问，便于当前阶段审计与复核
- 由于 2025 年公示附件在线抽取不稳定，本草案先以 2024 年 5 月 23 日的官方公示页作为可复核基础
- 后续应继续与 2025/2026 年最新招生资格公示进行校对

## 7. 下一步建议

基于这份草案，建议接下来按这个顺序推进：

1. 将名单转成标准库 seed JSON
2. 为每所学校补 `school_id`
3. 为每所学校补 `short_name`
4. 批量生成 aliases 候选
5. 对高频学校人工快速复核 aliases
6. 再进入搜索能力和校排映射能力开发
