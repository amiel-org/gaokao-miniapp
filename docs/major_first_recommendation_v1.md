# 专业优先推荐 V1

日期：2026-07-13  
适用项目：北京高考志愿填报小程序

## 1. 产品范围

本功能只推荐位于北京、且在当前产品口径中属于二本及以上的 46 所目标院校。二本以下、职业本科、提前批或普通批数据不稳定的院校不进入专业优先推荐池。

推荐对象不是抽象的“学校”，而是：

> 专业方向 + 北京高校 + 院校专业组 + 2026 招生专业 + 历史投档位次

## 2. 用户流程

1. 完成校排与北京市位次定位。
2. 选择专业优先、均衡推荐或学校优先。
3. 按顺序选择 1 至 3 个专业方向，或选择暂未确定专业。
4. 系统先匹配 2026 已核验招生专业，再在冲、稳、保同档内排序。
5. 结果卡片前置展示专业命中、全国优势证据、位次依据和专业组风险。

本地存储键：`latestMajorPreference`。

```json
{
  "version": "beijing-major-preference-v1",
  "mode": "major_first",
  "selectedDirectionIds": ["computer-ai", "electronic-automation"],
  "selectedDirectionLabels": ["计算机与人工智能", "电子信息与自动化"],
  "undecided": false,
  "updatedAt": "2026-07-13T00:00:00.000Z"
}
```

## 3. 专业归一口径

底层保留北京教育考试院官方目录中的原始招生专业名称。推荐层通过 `major-directions.js` 将实验班、双学位、师范、中外合作等招生名称映射到 19 个产品化专业方向。

例如：

- `计算机科学与技术(实验班)` 映射到 `计算机与人工智能`。
- `英语(师范)` 同时可映射到 `语言文学与人文`、`教育与心理`。
- 招生名称和附加标签不被删除，仍用于最终专业组核对。

专业优先排序只使用 2026 已核验专业、官方招生计划或真实专业种子。按选科生成的兜底方向只用于无数据时的展示，不参与专业命中和专业优先排序。

## 4. 全国专业实力证据

当前接入来源：

- 发布机构：教育部、财政部、国家发展改革委。
- 数据名称：第二轮“双一流”建设高校及建设学科名单。
- 发布时间：2022-02-11。
- 来源页面：`http://www.moe.gov.cn/srcsite/A22/s7065/202202/t20220211_598710.html`。

覆盖结果：

- 北京目标院校：46 所。
- 命中公开建设学科证据：28 所。
- 已映射专业方向的建设学科：84 条。

该来源用于判断“国家级优势方向”，不等同于本科专业精确全国排名。没有明确来源、年份和评价口径时，页面不得显示“全国第几”。北京大学、清华大学在教育部名单中为自主确定并自行公布建设学科，当前只展示学校层证据，不推断具体专业名次。

生成命令：

```powershell
npm run build:major-strength
```

## 5. 排序规则

冲、稳、保仍由历史投档位次窗口决定。决策模式只影响同档排序：

- `major_first`：没有命中所选专业方向的专业组不进入候选；专业优先级高于全国优势证据和学校平台。
- `balanced`：优先专业命中，同时允许其他专业组补足学校梯度。
- `school_first`：学校平台权重提高，专业命中仍作为解释和加分项。

排序因素包括：

1. 与目标位次的距离。
2. 专业方向是否命中及命中优先级。
3. 是否命中教育部公开建设学科证据。
4. 学校平台层次。
5. 中外合作、限女性等特殊条件。

## 6. 风险边界

- 院校专业组历史最低位次不等于目标专业最低位次。
- 进入专业组不代表一定进入目标专业。
- 结果必须展示专业组内命中专业数量和调剂风险提示。
- 招生专业、计划数、学费、外语和体检限制最终以北京教育考试院、院校招生章程和正式志愿系统为准。
- 第三方专业排名后续如需接入，必须保留来源、年份、评价对象、名次/档位和授权状态。
